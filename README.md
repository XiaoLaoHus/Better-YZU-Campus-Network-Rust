## Better-YZU-Campus-Network-扬州大学校园网自动登录脚本（Rust 版 · v3.0.0Lite）

`v3.0.0Lite` 保留 v3.0.0 的账号密码登录、图形界面与托盘，新增可选 SSO 认证网址：填写时直接使用并跳过自动获取，留空时自动获取认证入口。

* 这是一个用于实现扬州大学校园网自动登录和断线重连的脚本。脚本通过解析 SSO 入口 URL 中的易通网关参数，模拟 POST 请求完成认证。
* 本项目是原 [Python 单文件脚本](https://github.com/GUMOUXUAN/Better-YZU-Campus-Network) 的 Rust 重写版，原作者为GUMOUXUAN，使用 GitHub Actions 编译，可产出免运行时的单文件可执行程序。

### 1\. 功能概述

  * **自动登录：** 无需手动操作，自动完成校园网认证。
  * **断线重连：** 每隔 10 分钟（`interval_secs`，默认 600 秒）自动检查并尝试重新连接，确保网络持续在线。
  * **可选 SSO 认证网址：** 可以从浏览器地址栏复制完整校园网认证地址，填写后程序直接使用该地址中的会话参数，跳过自动获取；留空时沿用 v3.0.0 的自动获取逻辑。账号、密码和网络服务仍需填写。手动地址失效时可更新网址，或清空后恢复自动获取。
  * **Windows 图形窗口与托盘：** 双击启动，无控制台黑框；关闭或最小化窗口后仍在后台运行，点击托盘图标即可恢复。右键托盘可打开窗口或退出。
  * **自绘现代界面：** Windows 客户区使用 egui 绘制，文字与所在卡片背景保持一致，账号和密码输入文字水平、垂直居中；支持中文输入、密码遮蔽、键盘操作和日志复制。
  * **首次测试版提示：** 第一次打开图形界面会说明测试版仍有很多问题，并提供作者 QQ **2576381123**；确认后再启动自动连接，同一 Windows 用户后续启动不再重复提示。
  * **运行日志：** Windows 窗口显示最近 200 行日志；登录请求在独立线程执行，界面不会因等待网络而卡住。
  * **单文件发行：** 编译产物是单个可执行文件，无需 Python 和 Rust 环境，也不用先装解释器和依赖。

### 2\. 环境要求

#### 方式一：下载编译好的可执行文件（推荐）

前往 [Releases](../../releases) 页面，下载对应平台的压缩包，解压后即可运行，
无需安装任何运行时环境。

| 平台 | 压缩包 |
| :--- | :--- |
| Windows | `...-windows-x86_64.zip` |
| Linux | `...-linux-x86_64.zip` |
| macOS（Apple Silicon） | `...-macos-arm64.zip` |
| macOS（Intel / 黑苹果） | `...-macos-x86_64.zip` |

> 每个包里包含可执行文件、`config.example.toml` 和本说明文档。

#### 方式二：自行编译

需要先安装 [Rust 工具链](https://rustup.rs)：

```bash
cargo build --release
```

产物位于 `target/release/better-yzu-campus-network`（Windows 下为 `.exe`）。

#### 配置信息修改（必需）

**Windows 图形模式无需手动创建文件**：首次启动先阅读测试版提示，点击 **我已了解**，然后填写账号、密码并选择服务（SSO 认证网址可选），点击 **保存并连接**。其他参数使用默认值。已有有效配置会在确认提示后自动连接。旧版本配置无需补填网址，可继续自动获取认证入口。

**命令行模式**请复制配置模板并填入你的真实信息：

```bash
cp config.example.toml config.toml
```

然后编辑 `config.toml`：

| 字段名 | 描述 |
| :--- | :--- |
| **`user_id`** | 您的学号或用户名。 |
| **`password`** | 您的校园网密码。 |
| `auth_url` | 可选，完整校园网认证网址；默认空值。填写时直接使用，留空或缺少此字段时自动获取。 |
| **`service_index`** | 选择的网络服务，取值为 **1 到 5** 之间的整数。 |
| `interval_secs` | 可选，重连检查间隔（秒），默认 `600`。 |
| `danger_accept_invalid_certs` | 可选，是否跳过 TLS 证书校验，默认 `false`。 |

> **`service_index`** 对应服务：`1: 学校互联网, 2: 联通, 3: 移动, 4: 电信, 5: 校内免费`。

如需指定认证网址，连接校园网后，在弹出的认证页面复制地址栏中的完整地址，支持以下两种形式（示例中的 `...` 需替换为你的完整参数）：

```text
https://sso.yzu.edu.cn/login?service=http%3A%2F%2F10.245.2.20%2Feportal%2Findex.jsp%3Fwlanuserip%3D...
http://10.245.2.20/eportal/index.jsp?wlanuserip=...&mac=...&...
```

不要只复制 SSO 域名、无参数的门户首页或登录成功页面。若认证页未弹出，可用浏览器访问一个 HTTP 网站触发认证，再复制浏览器地址；也可将网址留空，由程序自动获取认证入口。

> `config.toml` 已被 `.gitignore` 忽略，账号、密码和个人认证 URL 不会进入版本库，也不会被编译进二进制文件。它们以明文保存在本机配置文件中。

### 3\. 使用方法

#### Windows：窗口与系统托盘

1. 解压 Windows 发行包，双击 `better-yzu-campus-network.exe`。第一次打开会显示 **测试版使用提示**：软件仍有很多问题，有问题请联系作者 QQ **2576381123**，支持复制 QQ。点击 **我已了解** 后继续；即使使用 `--minimized`，也会先显示提示，且确认前不会自动联网。
2. 填写 **学工号 / 账号**、**校园网密码**，在下拉框选择 **网络服务**，根据需要填写 **SSO 认证网址（可选）**，点击 **保存并连接**。账号和密码输入框文字居中，长 URL 输入框左对齐并可水平滚动，密码输入会遮蔽；有效的已有配置会自动连接。缺少或无效配置时，窗口不会因 `--minimized` 而隐藏。
3. 运行中可编辑并再次点击 **保存并连接**：先保存，再等待旧请求结束，最后启动新任务；不会同时运行两个联网线程。**停止重连**可以取消待重启任务，但不会注销已经建立的校园网连接。
4. 点击 **隐藏到托盘**、窗口 **×** 或 **最小化**，窗口隐藏但后台任务不会停止。单击 / 双击托盘图标或右键 **打开窗口** 恢复；图标可能位于通知区域的隐藏图标中。
5. 点击窗口或托盘菜单中的 **退出** 才会结束程序。退出会取消待重启任务并中断重连等待；在途探测 / 认证请求结束后关闭，耗时取决于网络超时，期间界面仍可响应。

> 测试版提示的确认状态保存在 `%LOCALAPPDATA%\Better-YZU-Campus-Network\ui-state.toml`，不含账号密码，与 `config.toml` 独立。切换配置文件或更新程序不会重复提示；删除此状态文件可以重新显示提示。状态不可读、内容损坏或无法保存时，下次启动会再次提示；保存失败会显示说明，不会阻止本次继续使用。命令行模式不弹出提示，也不写入确认状态。
> 客户区控件和提示弹窗由 egui 统一绘制，不依赖 Windows 原生输入框或 WebView2；系统窗口边框和通知区域菜单仍使用 Windows 接口。使用系统中文字体与 wgpu 图形后端，请保持 Windows 图形驱动正常；若字体或图形初始化失败，会显示启动错误。
> 默认每 600 秒检查一次，TLS 证书验证保持开启。已有配置中的这两个高级参数会在保存时保留；如需修改，请编辑配置文件。保存会重新序列化 TOML，不保留注释和未知字段。语法损坏的配置需明确确认后才会用表单和默认高级参数重建。
> 配置以明文保存在所显示的路径中，不是密码保险箱；请使用自己有写权限的私有目录，不要分享 `config.toml`。保存失败不会停止当前任务；先写临时文件再原子替换，避免半写入。不要把程序放在需要管理员权限才能写入的目录，也不要截图分享账号输入框。
> 图标采用绿色渐变背景、白色扬州大学校徽与 Wi-Fi 标识，用于 exe、窗口及托盘；校徽取自[学校官网提供的图片](https://www.yzu.edu.cn/__local/1/9C/B7/D2DA849218454F5605A81A3A442_5795DDB8_117BF.jpg?e=.jpg)。**本项目是第三方客户端，不代表学校官方应用或获得学校背书**。图标已嵌入 exe，无需额外资源文件。
> 状态文字描述后台任务，不把“任务运行中”误称为“已经联网”；实际认证结果请查看日志。托盘创建失败时窗口保持可见；资源管理器重启后会尝试恢复图标。
> 图形界面仅支持 Windows；Linux/macOS 及 Windows `--console` / `--once` 保持命令行模式。请勿重复启动多个实例。

```powershell
# 启动后直接隐藏到托盘（可用于快捷方式或任务计划程序）
.\better-yzu-campus-network.exe --minimized

# 命令行模式：不创建图形窗口和托盘
.\better-yzu-campus-network.exe --console
```

#### 命令行与配置路径

Windows 图形模式默认读取 **程序所在目录**的 `config.toml`；`--console`、`--once` 和 Linux/macOS 默认读取 **当前工作目录**。显式 `--config` 优先，相对路径基于当前工作目录。

```bash
# Linux/macOS 命令行运行；Windows 不带参数则打开图形窗口
./better-yzu-campus-network

# 指定配置文件路径
./better-yzu-campus-network --config /path/to/config.toml

# 只尝试登录一次后退出，不创建窗口（调试用）
./better-yzu-campus-network --once

# 查看帮助
./better-yzu-campus-network --help
```

`--minimized` 仅支持 Windows，不能与 `--console` 或 `--once` 一起使用。Windows 程序采用 GUI 子系统；在脚本中需要等待其结束时，可使用 `Start-Process -Wait`。

#### 后台常驻

Linux / macOS：

```bash
nohup ./better-yzu-campus-network > yzu.log 2>&1 &
```

Windows 可在“任务计划程序”中配置启动程序与 `--minimized` 参数，选择 **仅当用户登录时运行**，以便显示托盘图标；无需再使用 `-WindowStyle Hidden`。

### 5\. 故障排除

  * **`无法读取配置文件 config.toml`：** 还没有创建配置文件。复制 `config.example.toml` 为 `config.toml` 并填写。
  * **登录失败：** 请检查 `config.toml` 里填的 **`user_id`** 和 **`password`** 是否准确无误。
  * **`网络连接错误：可能未联网或服务器无响应。`：** 当前设备不在校园网内，或网关不可达。
  * **手动网址参数不完整：** 填写的 SSO 地址必须带 `service` 参数，门户地址必须带 `wlanuserip` 会话参数。请复制完整认证网址，或清空 `auth_url` 以恢复自动获取。旧配置无需添加此字段。
  * **登录接口返回 HTML 或空响应：** 程序会尝试系统代理、直连和兼容 HTTP 路径；切换路径时会重新取得会话 Cookie。日志只显示状态码、响应类别和长度。若仍失败，请关闭 VPN / 代理，确认网址来自当前设备和本次校园网连接，不包含句末中文标点；填写网址时始终使用该网址，不会改为自动获取。
  * **自动获取收到外网站点页面：** 外网页面不代表取得认证入口；程序会继续尝试直连和兼容路径。若所有路径都没有入口，请检查是否已在线、是否使用代理，或手动填写当前认证网址。
  * **URL 原先可用，现在登录失败：** 会话参数可能随网络、设备或连接变化而失效。重新打开认证页面，复制当前完整 URL，然后点击 **保存并连接**。填写网址时不会自动获取或替换该地址；也可清空网址，恢复自动获取。
  * **服务器响应格式错误：** 脚本在断网或半连接状态下可能无法获得标准的 JSON 响应。脚本已添加错误处理，会自动重试。
  * **其他错误：** 可以带着截图联系我，虽然我可能也解决不了
